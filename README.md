# My Profile Website

A simple Next.js profile website showcasing biography, resume highlights, and LinkedIn contact.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run locally:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Deployment

- Deploy to Vercel by connecting this repository.
- For GitHub Pages, export a static site with `npm run build` and `npm run export`, then serve the `out` folder.
